    Project 1 // _invoice-guard

    Invoice Guard

    2026 · PayPal AI Hackathon entry

    Every invoice gets three checks: PayPal confirms it’s real, the payment history says whether the sender and amount are expected, and a scam-detection model reads the wording. Plain, tested rules then decide to pay, block or ask the owner, and Claude writes a short note explaining any stop. It never pays a first-time sender without asking.

    Project 2 // _split-seek

    SplitSeek

    2026 · Devpost “Build With AI: Basics” hackathon

    LOG footage is flat and grey, so dozens of clips from one trip look almost identical as thumbnails. SplitSeek is a small macOS app you keep open next to your video editor: point it at a folder, type something like “a waterfall” or “llamas”, and it ranks the matching moments with timestamps, confidence and a preview that starts at the right second.

    A Rust engine pulls a frame every 2 seconds with ffmpeg, decoding only keyframes on the Mac’s video hardware (about 30× faster on 4K HEVC), caches them, and asks TypeSafe’s Jev image model one yes/no question per frame. Back-to-back matches are joined into stretches and ranked. Original clips are only ever read, never changed.

    • Rust
    • Tauri 2
    • JavaScript
    • ffmpeg
    • VideoToolbox
    • TypeSafe Jev

    Project 3 // _fitmeai

    FitMeAI

    2025–2026

    One click picks a top, bottoms, outerwear and accessories that go together, each linked to its product page. Visitors can steer it by occasion, colours and budget, and TypeSafe’s Jev model decides what works together. A daily job refreshes thousands of products into Cloudflare KV, split so each request reads only what it needs. Built on boohooMAN’s public men’s catalogue as a test store; not affiliated with boohooMAN.

    Project 5 // _migration-map

    Migration Map

    2024 – 2026

    An interactive world map built on live data from the UN refugee agency (UNHCR). Click a country to see where its people have fled, with figures for refugees, asylum seekers and people displaced inside the country; click a second country to see a single route, such as how many Syrian refugees live in Germany. Every view has its own link, so a map can be shared exactly as you see it.

    It started as a Java desktop app and is now a web app built without a framework. I built it to bring together my two majors, Global Studies (Migration) and Computer Science.

    • JavaScript
    • HTML

    • UNHCR API
    • Java
